# NestJS Backend Learning

> 프론트엔드 경험을 바탕으로 백엔드 설계·구현·운영까지 익히는 16주 학습 프로젝트

## 목표

- Node.js와 HTTP의 동작 원리를 이해하고 API를 직접 구현한다.
- NestJS로 모듈화된 서버와 비즈니스 로직을 설계한다.
- PostgreSQL과 SQL을 바탕으로 데이터를 모델링하고 안전하게 처리한다.
- 인증·인가, 파일 처리, 캐시, 비동기 작업 등 실제 서비스에 필요한 기능을 구현한다.
- 테스트, Docker, 배포, 모니터링까지 서비스 운영의 기본 흐름을 익힌다.

## 배경 및 학습 방식

- 선수 지식: TypeScript, React, Next.js 경험
- 학습 기간: **16주(기본 계획)** — 진도에 따라 유연하게 조정
- 학습 시간: **매일 21:00–23:00 (KST)**
- 학습 원칙: **개념 이해 → 최소 예제 → 기능 확장 → 정리 및 커밋**
- 각 주의 주제와 완료 기준은 [`ROADMAP.md`](./ROADMAP.md)에서 확인

> 주 14시간의 계획 학습 시간은 목표치이며, 진행 상황에 따라 과제를 나누거나 복습일을 추가한다.

## 학습 범위

| 주차 | 주제 | 주요 결과물 |
| --- | --- | --- |
| 1–2주 | Node.js / HTTP | 의존성 최소화한 메모 API |
| 3–4주 | NestJS 핵심 구조 | 할 일 관리 API |
| 5–7주 | PostgreSQL / SQL / Prisma | 게시판 API |
| 8–10주 | 인증·인가 / 보안 | 회원·권한 관리 API |
| 11–13주 | 실무 백엔드 | 파일 공유·알림 기능 |
| 14–16주 | 테스트 / 배포 / 운영 | 서비스 배포 및 운영 점검 |

## 최종 프로젝트: 팀 프로젝트·파일 관리 서비스

팀원 초대, 역할별 권한, 작업 관리, 파일 업로드, 알림을 제공하는 서비스.

**예정 기술 스택**

- 프론트엔드: Next.js / TypeScript
- 백엔드: NestJS
- 데이터베이스: PostgreSQL / Prisma
- 캐시·작업 큐: Redis / BullMQ (필요할 때 도입)
- 테스트·배포: Jest 또는 Vitest, Docker, Dokploy

**MVP 범위**: 로그인, 프로젝트·작업 CRUD, 멤버별 권한, 파일 첨부, 기본 알림.

추가 기능은 MVP 이후에 구현한다.
